# Mobile Game Success Playbook

Reference file of what makes four mobile hits work: **Magic Sort!** and **Block Out!** (Grand Games), **Gossip Harbor: Merge & Story** (Microfun) and **Smash Fest!** (Flow Games). It covers gameplay, monetization, retention, live ops and, most importantly, **why each game's core is built for marketing**.

**How to use this file:** Share it in a chat together with a new game idea (use the template in Part J). Claude should:
1. Identify which strategy pattern the idea follows (Part F) and which game it is closest to.
2. Score it with the checklist in Part I (gameplay, monetization, retention, marketability, timing).
3. Suggest features to borrow, adapt or improve, and flag risks.
4. Propose 3–5 ad creative concepts the core could support (Part E).

**Last updated:** 23 October 2026
**Confidence labels:**
- **[Store]** = confirmed on the App Store listing (Cyprus store, Oct 2026 unless noted)
- **[Report]** = industry analysis (AppMagic, Naavik, Gamigion, Felix Braberg, Mobidictum, Deconstructor of Fun, SocialPeta, Udonis, Segwise, GameRefinery, PocketGamer.biz, FoxData, AppGrowing, 36Kr, LinkedIn analyst posts). Revenue and download figures are third-party estimates.
- **[Inferred]** = reasonable conclusion, not directly confirmed

# PART A — MAGIC SORT! (Grand Games)

## A1. Snapshot
| Item | Value |
| --- | --- |
| Developer | Grand Games A.Ş., Istanbul, founded early 2024 [Report] |
| Founders | Ex-Good Job Games team (Zen Match, acquired by Moon Active) [Report] |
| Genre | Water/liquid sort puzzle, hybrid-casual, level-based [Store] |
| Theme | Wizard, magic potions, cauldron, spells [Store] |
| App size / languages | ~618 MB on iOS; 11 languages [Store] |
| Rating | 4.6 / 5; age 13+ [Store] |
| Peak performance | With Block Out, held #1 and #2 on US iOS download charts; the pair earned ~$11M IAP in 30 days [Report] |
| Revenue efficiency | One 30-day window: $3.3M IAP + ~$1M ads from ~478k DAU; ARPU ~$8.68 vs Hexa Sort ~$4.28, Bus Out ~$1.95 [Report] |
| Funding (studio) | $3M pre-seed, $30M Series A, $70M Series B ($103M total) [Report] |

**Summary:** Took a proven, low-quality, ad-heavy genre (water sort) and upgraded it with premium polish, fail-moment IAP, light meta and fast live ops.

## A2. Core strategy
- Water sort games already had 50M–100M first-year downloads and 40–50% D1, but low production, no meta, no live ops, under 10% D30. [Report]
- Magic Sort fixed each weakness: polish, hybrid monetization, progression, content cadence, performance marketing. [Report]

## A3. Core gameplay
| Feature | Details | Why it works |
| --- | --- | --- |
| One-tap pour | Tap bottle, tap target; same color + space only [Store] | Instantly readable |
| No timers, no move limits | Think freely [Report] | Relaxing positioning |
| Dead-end detection | Detects unsolvable state instantly [Report] | Triggers main monetization moment |
| Undo / Shuffle | Escape tools [Store] | Lower frustration; sellable |
| Level blockers | Hidden colors, special bottles [Report] | Freshness without new rules |
| Daily puzzle | Special daily level [Report] | Daily habit |

## A4. Level design
- Tuned difficulty curve with deliberate hard and super-hard levels. [Report]
- Dynamic easing: after failing level 26 once, the retry removes one color. [Report]
- Every update advertises 100 new levels. [Store]

## A5. Monetization
**Engine — monetize the fail moment:** stuck → detected instantly → "+1 Bottle" offer for coins → coins earned or bought. Like Candy Crush's +5 moves. [Report]

| Source | Details |
| --- | --- |
| +1 Bottle (coins) | Main IAP driver [Report] |
| Coin packs | 1,000 = €1.99; 5,000 = €8.99 [Store] |
| Starter bundle | €0.99 [Store] |
| Themed bundles | Apprentice €5.99, Magician €9.99, Sorcerer €22.99 [Store] |
| Special Offers / event purchase | €0.99–€9.99; Endless Portal €6.99 [Store] |
| Ads | Rewarded + interstitials from level 22 [Report] |

**Mistakes (reviews):** feels unwinnable without paying after day one; misleading ads; hidden close buttons; loud ads. [Store reviews]

## A6. Retention, live ops, production
- Weekly, country and global leaderboards; daily challenge; win streaks [Report]
- Ingredient collection and cauldron booster crafting [Store]
- Update every 1–2 weeks with 100 levels; events Broom Streak, Magic Streak, Jetpack Race [Store] [Report]
- Near Royal Match-level polish; satisfying liquid animation [Report]

# PART B — GOSSIP HARBOR: MERGE & STORY (Microfun)

## B1. Snapshot
| Item | Value |
| --- | --- |
| Developer | Microfun Limited (China; Hong Kong entity); 400+ employees [Store] [Report] |
| Genre | Merge-2 + story + restaurant restoration/decoration [Store] |
| Release | 2022; broke out late 2024 [Report] |

| Rating | 4.4 / 5; age 13+ [Store] |
| Audience | ~79% women, average age ~32 [Report] |
| Scale | 90M+ downloads; ~5.4M DAU, ~28M MAU; ~$677M lifetime revenue [Report] |
| 2026 growth | Q1 2026 revenue ~$270M (+172% YoY); first month above $100M net in March 2026 [Report] |
| Markets | Revenue: US ~40%, Japan ~9%, Germany ~6%. Downloads: US 16%, Brazil 12%, Indonesia 6%, Türkiye 5% [Report] |

## B2. Core gameplay
- Merge-2 board: generators produce items, merge identical items to fill customer orders → coins. [Report]
- Coins → renovate areas → story advances. Simple currency loop. [Report]
- Energy: every generator action costs energy that refills slowly. Main gating and monetization tool. [Report]
- Core loop judged stronger than Merge Mansion / Travel Town. [Report]

## B3. Story and meta
- Quinn discovers infidelity, divorces, returns with her daughter to her family's burned restaurant; then poisoning and sabotage mystery. [Report] [Store]
- Mystery, romance, drama, friendship, LGBTQ+ relationships; short dialogue. [Report]
- Decoration choices (floors, wallpaper, furniture). [Store]
- New episode every Friday, like a serialized show. [Store]

## B4. Monetization
| Source | Details |
| --- | --- |
| Diamonds | Refill energy, skip timers, decorations [Report] |
| Gem and energy packs | €1.99–€5.99; Premium Energy Bundle €3.99 [Store] |
| Themed bundles | Coffee €2.99, Seafood €3.99 [Store] |
| Holiday bundles | Thanksgiving/Black Friday $2.99–$7.99 [Report] |
| Rewarded ads | When out of energy; est. 15–20% of revenue [Report] |
- Sequence of early offers rather than one starter pack; event passes on top of a seasonal pass. [Report]
- ARPDAU ~$0.26 vs Travel Town ~$0.35, but better retention. [Report]

## B5. Live ops
- Live ops shown in the first sessions; multiple parallel events from mid-early levels. [Report]
- Win Streak format; album/collection events; themed events every ~2–4 weeks rewarding decorations. [Report] [Store]
- Speed competitions; new hybrid modes (match-3 + merge, April 2026). [Report]
- ~4 updates per month. [Report]

## B6. Weaknesses
- Energy wall (~10 minute sessions); ads don't match gameplay; story criticized as guilt-driven. [Store reviews]

# PART C — BLOCK OUT! – COLOR SORT PUZZLE (Grand Games)

## C1. Snapshot
| Item | Value |
| --- | --- |
| Developer | Grand Games A.Ş. (same studio as Magic Sort) [Store] |
| Release | October 2025 (iOS first; reported as not yet on Google Play at the time of one analysis) [Report] |
| Genre | Slide-block color puzzle (blocks slide to matching-color doors/gates), level-based [Store] |
| Inspiration | Rollic's Color Block Jam (the biggest hybrid-casual block puzzle: $25M in Q1 2025) [Report] |
| Theme | Light themed "regions" (dinosaurs, Florence, Mona Lisa workshop, portraits) [Store] |
| App size / languages | ~525 MB on iOS; 11 languages [Store] |
| Rating / age | 4.5 / 5; age 4+ (wider audience than Magic Sort's 13+) [Store] |
| Chart | #1 Casual on the Cyprus store (Oct 2026) [Store] |
| Revenue | Scaled to $250K+ daily IAP [Report]; with Magic Sort ~$11M IAP in 30 days [Report] |
| Studio context | Grand portfolio estimated at $600K+ per day [Report] |

**Summary:** Grand Games repeated the Magic Sort formula on a different proven mechanic: take the hottest hybrid-casual hit (Color Block Jam), polish it, add casual-style meta and IAP depth.

## C2. Core gameplay
- **Slide colored blocks to matching doors** to clear them. [Store]
- **Dynamic elements:** moving elevators and block generators. [Store]
- **Key design difference vs Color Block Jam:** levels unlock in sections as you progress, instead of showing the whole puzzle at once → lower cognitive load, more approachable. [Report]
- **Deterministic levels with time limits:** same layout every retry, so players learn and improve. [Report]
- **Hard level labels** set expectations before difficult levels. [Report]
- **Boosters** to escape tough spots. [Report]
- **Offline play.** [Store]

## C3. Obstacle pipeline (new mechanic every ~2 weeks)
Recent updates each introduced a new blocker [Store]:
- Locked Shutter (clear same-color gem blocks to unlock)
- Color Grinder (clear same-color blocks to open the path)
- Multilayer blocks (remove outer layers one by one)
- Ivy (clear blocks to cut back ivy and reveal doors)
- Color Shutter; Blocker Board Generator

**Lesson:** a steady stream of small rule twists keeps a simple core fresh for thousands of levels.

## C4. Meta and live ops
- **Journey map** with themed regions (Dino Discovery, Dinosaur Chase, Egg Rush, Florence, Mona Lisa workshop, Perfect Portrait). [Store] [Report]
- **Leaderboards / leagues** (500 league levels mentioned in a review). [Store review]
- **Collection system** unlocking at level 95. [Report]
- **Events introduced early** and expanding over time [Report]:
  - Lily Leap: win levels without losing to hop across lily pads for a big prize (streak event)
  - Streak Race: race a dino to the finish line
  - Balloon Ride journey; Task Carnival (task/quest event)
  - Revamped Daily Gift
  [Store]
- Updates roughly weekly to bi-weekly. [Store]

## C5. Monetization (IAP-heavy)
| Source | Details |
| --- | --- |
| Coin packs | 1,000 = €1.99; 5,000 = €8.99; 10,000 = €17.99 [Store] |
| Starter bundle | €1.99 [Store] |
| Brick Bundles | €5.99, €9.99 [Store] |
| Premium Bundle | €22.99 [Store] |
| **Block Pass** | €9.99; raises maximum lives and also acts as the fail offer [Store] [Report] |
| Big special offers | €29.99 and €69.99 [Store] |
| Lives system | Lives cap (pass increases it) [Report] |
| Ads | Store lists ads (CY); US listing advertises "Ad Free Experience" [Store] — likely varies by market or test [Inferred] |

**Key idea:** The pass is not just cosmetic; it changes core limits (more lives) and doubles as the rescue offer when you fail.

## C6. Weaknesses (reviews)
- Timer annoys some players; they want a no-timer option. Competitors literally market "No Timer" in their names (Block Buster – No Timer, Block Jam Out: No Timer). [Store]
- Progress bug: replaying 500 league levels after updates. [Store review]

# PART D — SMASH FEST! (Flow Games)

## D1. Snapshot
| Item | Value |
| --- | --- |
| Developer | Flow Games, Istanbul (very young studio) [Store] [Report] |
| Team background | CEO ex-Good Job Games; CTO ex-Peak Games and Fomo Games; art director ex-Dream Games; artist ex-Grand Games [Report] |
| Release | First iOS version Dec 2025 (soft launch); global release early June 2026 [Store] [Report] |
| Genre | 3D physics cannon knockdown ("smash puzzle"), hybrid-casual [Store] |
| App size / languages | ~344 MB on iOS; English only on the store [Store] |
| Rating / age | 4.7 / 5; age 4+ [Store] |
| Growth | ~2M downloads in June → 10.2M in July 2026; IAP $692K → $3.4M [Report] |
| Peak | 4th most-downloaded game worldwide (week of July 13–19, 2026); top 10 grossing hybrid-casual in July [Report] |
| Lifetime | 15M+ installs; IAP ~$6.3M–$8.9M depending on source [Report] |
| Revenue mix | Reportedly mostly ad revenue; IAP figures understate it [Report] |
| Funding | $46M round, ~75% from Tencent, about 4 months after launch [Report] |
| Google Play | Pulled from Google Play by end of July 2026 (reportedly linked to a dispute; AppMagic notes a name reference to Toon Blast's event) [Report] |

## D2. Origin: a live ops minigame turned into a full game
- The mechanic comes from **Cannon Fest**, a limited-time event minigame in Peak Games' Toon Blast (seen since late 2024 and used in Toon Blast's playable ads). [Report]
- Flow Games extracted this player-validated fun, rebuilt levels, visuals and monetization around it, and released it as a lighter standalone game made for user acquisition. [Report]
- The mechanic is old (Angry Birds, Boom Blox); the novelty is packaging and timing. [Report]

**Lesson:** Big casual games' event minigames are pre-tested prototypes. Their popularity (and their use in ads) signals proven fun.

## D3. Core gameplay
- **Aim → fire cannon → smash stacks** of cans, jars, stones, boxes. Adjust angle, power, timing. [Store] [Report]
- **Limited shots per level**; clear all items to win. [Report]
- **Chain reactions:** one good shot topples many targets. [Store]
- **Realistic physics and feedback:** jars shatter, heavy stones need more force or repeat hits; each item type has its own sounds and movement. [Report]
- **Boosters and obstacles** layered over time; hundreds of structural layouts. [Report]
- **High-quality 3D visuals,** colorful festival environments. [Store]

## D4. Monetization (deliberately simple)
| Source | Details |
| --- | --- |
| Coin packs | Mini €1.99 → Mega €99.99 [Store] |
| Fail Offer | €5.99 [Store] |
| No Ads | €9.99 [Store] |
| Bundles | Medium €22.99, Large €44.99 [Store] |
| Ads | Interstitials from level 20 + rewarded [Report] |
| No pass, no piggy bank, no layered special offers | [Report] |

**Offer data (iOS, US):** [Report]
- $7.99 coin pack = 28% of IAP revenue; $14.99 pack ≈ 21%.
- $1.99 pack = most purchases and 52% of first purchases.
- $9.99 No Ads = only 7.6% of revenue but 17% of first purchases → ads work as a conversion tool.

## D5. Retention and weaknesses
- Minimal meta and live ops; relies on the novelty of the core. [Report]
- Players ask for more power-ups, more block types, cannon skins. [Report]
- Complaint that leftover balls don't give bonus points. [Store review]
- Ad frequency increases in later levels. [Report]
- Store update notes are generic ("Bug fixes and improvements"), no event marketing. [Store]

## D6. The follower problem
- 80+ "smash" physics games appeared within months; large studios (Moon Active, Azur, Supercent, Tripledot) launched or tested their own. [Report]
- **Royal Smash!** (Cypher Games) reached ~$6.6M IAP vs Smash Fest's ~$6.3M by adding casual-style live ops early: a task-gated piggy bank at level 11, win streak at 16, chain offer, weekly tasks at 40, competitive event at 55, and "Royal"-style branding. [Report]
- Flow Games responded with a second title, Smash Land! (August 2026). [Report]

**Lesson:** A trending core gets you to the top fast, but without meta and live ops, followers with deeper systems catch up within weeks.

# PART E — WHY EACH CORE IS BUILT FOR MARKETING

The most important lesson: **every one of these games picked a core whose key moment can be shown in an ad in a few seconds.** The core decides how cheap and scalable user acquisition will be.

## E1. Gossip Harbor — emotional story engine
1. **The protagonist is the hook.** A betrayed single mother rebuilding life with her daughter is universal and generates endless ad scenarios. [Report] [Inferred]
2. **The mechanic reads as "rescue".** Merging to repair, warm, feed or rebuild = saving the family. [Report]
3. **Ad formula** (Segwise): 100% open on family hardship; 83% weather suffering; 67% structural collapse; 67% mother or daughter in the hook; 90% longer than 50 s (sweet spot 54–58 s); 67% end unresolved; 25% "our ads aren't fake" meta-commentary. Arc: crisis → partial merge fix → setback → cut. [Report]
4. **The game partly delivers the promise:** weekly cliffhanger episodes. [Store] [Inferred]
5. **Narrow audience** (~79% women, ~32) → efficient targeting. [Report]
6. **Themed events = fresh creative and ASO visuals** (in-app events, seasonal icons). [Store] [Report]
7. **Volume:** 600–800 active creatives; ~86% of spend on AppLovin; heavy localization. [Report]

## E2. Magic Sort — satisfying readable puzzle
1. **One-second readability:** colored liquid in bottles. [Inferred]
2. **Satisfying pouring visuals** ideal for silent autoplay. [Report]
3. **Built-in "can you solve this?" challenge** → 8 playable ads on AppLovin. [Report]
4. **The near-fail moment** ("one move left") works as an ad ending. [Inferred]
5. **Theme gives the genre a brand** (potions, spells). [Store]
6. **Focused channels:** started on AppLovin and Meta only. [Report]

## E3. Block Out — brain-test challenge
1. **Instantly readable goal:** colored block → same-colored door. [Store]
2. **"Brain test" / IQ challenge framing** is the proven ad style for this genre (used by Color Block Jam and Bus Escape) — viewers self-assess "could I solve this?". [Report]
3. **Satisfying clears** (blocks shredding through gates) look good in short videos. [Report] [Inferred]
4. **Deterministic levels** mean ads can show a specific real level that players can actually find in-game. [Inferred]
5. **Age 4+ and abstract theme** → very broad targeting. [Store]
6. **Proven traffic:** the genre already had huge ad-driven audiences; Grand captured that demand with a better product. [Report]

## E4. Smash Fest — pure destruction spectacle
1. **Destruction is the most watchable action in mobile ads:** towers collapsing and jars shattering need no explanation, no language, no tutorial. [Store] [Inferred]
2. **Chain reactions create a payoff moment** every few seconds — perfect for 15-second videos. [Store]
3. **Skill + luck tension:** "will this shot clear it?" keeps viewers watching to the end. [Inferred]
4. **Already ad-tested:** Toon Blast used Cannon Fest in playables; the format was proven in ads before Smash Fest existed. [Report]
5. **One-thumb playable ad:** aim and release is the ideal playable format. [Inferred]
6. **Built "for user acquisition placement":** lighter, more direct standalone version of the minigame. [Report]
7. **Trend effect:** the mechanic spread into other genres' ads (Toon Blast, Mystery Town, Top Tycoon). [Report]

## E5. Universal marketability principles
1. **Key moment visible in 3 seconds** (pour, merge, slide-and-clear, smash).
2. **The action should be satisfying to watch** (fluid, shatter, chain reaction).
3. **The mechanic should carry meaning** (rescue, fix, solve, destroy).
4. **Built-in cliffhanger or near-fail** for the ad ending.
5. **A character or theme people care about** — or pure spectacle that needs none.
6. **"Can you solve this?" challenge** for puzzle playables.
7. **Know the exact audience** and align tone, art and ads.
8. **Live ops that produce new visuals** for ads and store pages.
9. **Creative volume and testing:** many variations, localization.
10. **Check minigames and ads of big games** — a mechanic already used in their playables is pre-validated for UA.

## E6. Warning about misleading ads
- Magic Sort and Gossip Harbor both get reviews saying ads don't match gameplay; the smash trend is also being used in misleading ads by unrelated games. [Store reviews] [Report]
- Mismatch causes early churn, angry reviews, and can break store and ad network policies.
- **Safer:** show real gameplay or a real in-game mode; keep the emotional hook true to the game.

# PART F — STRATEGY PATTERNS

| Pattern | Example | How it works | Best for |
| --- | --- | --- | --- |
| **1. Level up a proven genre** | Magic Sort (water sort), Block Out (Color Block Jam) | Find a mechanic with huge traffic but weak competitors; add polish, IAP depth, meta, live ops | Small/medium teams |
| **2. Story wrapper** | Gossip Harbor | Familiar mechanic + serialized drama + decoration; emotional ads | Large teams with content pipelines |
| **3. Extract a minigame** | Smash Fest (from Toon Blast's Cannon Fest) | Take a validated event minigame from a big game, rebuild it as a standalone UA-friendly title | Fast-moving small teams |
| **4. Fast follower with deeper systems** | Royal Smash! | Copy a trending core within weeks, add early live ops, piggy bank, streaks, familiar branding | Teams with strong live ops tech |
| **5. Portfolio of focused bets** | Grand Games (Magic Sort, Car Match, Block Out, Arrow Jam) | Small autonomous teams each take a proven puzzle trend; not all succeed, winners scale | Studios with several teams |

**Common thread:** None of these games invented a brand-new mechanic. They won through **timing, polish, monetization design, live ops and marketing fit.**

# PART H — LESSONS FOR A SMALL TEAM
1. **Start from a proven mechanic** with big traffic and weak or simple competitors.
2. **Make the core look amazing in 3 seconds** before building anything else.
3. **Design one strong fail/stuck moment** and sell the rescue (+1 bottle, extra shot, extra life).
4. **Keep the first monetization simple** (coin packs, no-ads, fail offer, starter pack); add a pass that changes real limits later.
5. **Delay interstitials until level ~20** and use them partly to sell "No Ads".
6. **Plan a steady obstacle/twist pipeline** (one new blocker every ~2 weeks).
7. **Add early live ops:** streak event, race event, journey map, collection — the follower with deeper systems wins.
8. **Watch big casual games' events and playable ads** for the next mechanic.
9. **Offer options players ask for** (e.g., no-timer mode) — competitors use them as selling points.
10. **Move fast:** trends get 80+ clones within months.
